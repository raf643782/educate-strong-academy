# StrongKidz — Information Required From Educate Strong Before Sessions Open

This lists everything Educate Strong needs to confirm or supply before real StrongKidz sessions can be booked. The public page currently and honestly marks all of this as "to be confirmed" — nothing below is a launch blocker for the page itself, only for opening real bookings.

**Last updated:** Priority 2 (Master Continuation Programme) — 2026-07-23.

---

## Required before sessions open

| Item | Where it will appear | Why it's needed |
|---|---|---|
| Location and exact venue address | Session details | Parents need to know where to bring their child |
| Age range (minimum and maximum) | Session details | Determines eligibility |
| Group size | Session details | Sets booking capacity |
| Session duration | Session details | Sets parent expectations and scheduling |
| Pricing (single session and any block booking) | Session details | Required before any payment can be taken |
| Session dates and frequency | Session details | Required to open real bookings |
| Coach name(s) delivering sessions | Coach section | Parents reasonably expect to know who is coaching their child |
| DBS confirmation for each named coach | Safeguarding section | Currently replaced with a holding statement; must be confirmed before real claims can return to the page |
| Safeguarding qualifications held by each coach | Safeguarding section | Same as above |
| Named safeguarding lead and contact route | Safeguarding section | Required for a functioning safeguarding process, not just a claim |
| Parent attendance and drop-off policy | Logistics | Needed for the actual booking/session-day experience |
| Medical information and emergency contact process | Consent form | Needed before any child can safely attend |
| Photography and filming consent process | Consent form | Needed before any session photography could be used anywhere |
| Booking process | Booking flow | Needed to move beyond Register Interest to real bookings |
| Cancellation and refund policy | Booking flow | Needed once payment is involved |

## Recommended before sessions open

| Item | Where it will appear | Why it's recommended |
|---|---|---|
| Required clothing and equipment | Session details | Reduces first-session friction for parents |
| Accessibility information | Session details | Supports inclusive access from day one |

## Can be added after launch

| Item | Where it will appear | Why it can wait |
|---|---|---|
| Trial session policy | Booking flow | A nice-to-have refinement, not required for the first bookings |

## How to respond

For each item above, a short written confirmation is enough (no particular format required). Where a document already exists (e.g. a safeguarding policy, a DBS certificate reference, a pricing sheet), please just point to it rather than retyping it — we'll wire the confirmed wording into the site directly. Nothing here needs to go through this chat in a special format; a plain email or shared document works.
